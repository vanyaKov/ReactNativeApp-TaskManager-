# React Native Task Manager

Mobile app for creating and managing work tasks.

## Features

Create tasks with title, description, location, and deadline
Task list with status and dates
Sort by creation date or status
Task details screen
Update status: In Progress, Completed, Cancelled
Delete tasks
Local storage (data persists after the app is closed)

## Stack

React Native, Expo, Expo Router
TypeScript
Zustand
AsyncStorage

## Run locally

```bash
npm install
npx expo start
```

## Project structure

Feature-Sliced Design: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.
